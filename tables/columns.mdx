Columns define the information stored on each record. A good column design makes records easy to create, search, automate, and report on.

## Common Column Types

| Column Type | Use It For |
|-------------|------------|
| **Text / Long text** | Names, descriptions, instructions, notes, addresses. |
| **Number / Currency / Percent** | Quantities, costs, rates, margins, scores, completion percentages. |
| **Date / Date-time** | Due dates, expected delivery dates, creation dates, appointment times. |
| **Dropdown / Status / Choice** | Controlled values such as priority, approval state, category, or process status. |
| **Relation** | Links to records in another table, such as Vendor, Customer, Asset, PO Items, or Dispatch Lines. |
| **User / Team** | Owners, assignees, approvers, responsible teams. |
| **File / Image / Signature** | Supporting documents, photos, proof of delivery, signed approvals. |
| **Boolean** | Yes/no flags such as Active, Requires Approval, or Is Urgent. |
| **Location** | Geo-coordinates or site locations for field work. |
| **Button** | User-triggered business actions such as Generate PO, Confirm, Dispatch, or Send Email. |
| **Computed / Derived** | Read-only values calculated by ERPLite, such as totals, lookups, and rollups. |

## Important Column Settings

| Setting | Why It Matters |
|---------|----------------|
| **Display name** | What users see in the table, forms, reports, and filters. |
| **Internal name** | The stable field identity used behind the scenes. Avoid changing business meaning after records exist. |
| **Required** | Prevents users from saving incomplete records. |
| **Default value** | Pre-fills common values. |
| **Display column** | Controls how this record appears when another table links to it. |
| **Dropdown options and colors** | Makes statuses and categories easier to scan. |
| **Column permissions** | Controls who can view or edit sensitive fields. |
| **Conditional rules** | Shows, locks, or requires fields based on other field values. |
| **Derived field settings** | Makes the field read-only and calculated automatically. |
| **Relation filter** | Limits which related records can be selected. |
| **Create/link mode** | Controls whether users can link existing related records, create new related records, or both. |

## AI Guidance

### When to Use This Feature

An AI should add or update columns when the business needs to collect, calculate, restrict, or display information on a record.

Use the most specific field type available:

- Use **Date** instead of Text for dates.
- Use **Currency** instead of Number for money.
- Use **Relation** instead of a copied name from another table.
- Use **Dropdown/Status** instead of free text for values used in filters, workflows, or reports.
- Use **Derived** instead of asking users to manually calculate totals or copy values.

### How to Use It

<Steps>
  <Step title="Open table settings">
    Open the table, then open **Table settings** or the column manager.
  </Step>
  <Step title="Add or edit the column">
    Choose the field type that matches the business meaning. Give it a clear display name.
  </Step>
  <Step title="Configure type-specific settings">
    Add dropdown options, relation target table, number/date settings, or file/image rules as needed.
  </Step>
  <Step title="Configure behavior">
    Set required/default behavior, derived calculation, conditional rules, or permissions.
  </Step>
  <Step title="Save and test with a record">
    Create or edit a sample record and confirm the field behaves as intended.
  </Step>
</Steps>

### How to Verify

The AI should verify:

- The field appears with the correct label in create, edit, detail, table, and view screens.
- Required fields block save with a clear message.
- Dropdown values and colors match the business process.
- Relation fields show readable records and enforce any filters.
- Derived fields are read-only and update from source values.
- Users without permission cannot see or edit restricted columns.
- Exports and imports use a clear, round-trippable format for the field.

## Choosing Between Similar Fields

| If the business says... | Use |
|-------------------------|-----|
| "Choose one status from a fixed list" | Status or dropdown |
| "Choose multiple tags" | Multi-select |
| "Attach a proof document" | File |
| "Attach photos" | Image |
| "Select the responsible person" | User |
| "Select the operating team" | Team |
| "Link this order to a customer" | Relation |
| "Calculate total quantity or amount" | Derived formula or rollup |
| "Copy GST number from vendor" | Derived lookup |

<Warning>
Be careful when editing a status field that is controlled by a workflow. Changing status options can break workflow transitions if the workflow expects the old values.
</Warning>
