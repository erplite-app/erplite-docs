Configurations is where administrators and AI assistants shape how ERPLite works for a business process. It brings together workflow setup, automations, document mappings, display preferences, and dashboard configuration.

## What Belongs in Configurations

| Area | Use It For |
|------|------------|
| **Workflows** | Status paths, action buttons, guards, and links. |
| **Automations** | Background actions, notifications, record updates, schedules, and webhooks. |
| **Document mappings** | Pull data from one record into another, such as PO to GRN or SO to Dispatch. |
| **Display preferences** | Control how records and tables should appear to users. |
| **Home dashboard** | Configure role, team, or user-specific home widgets. |
| **Record widgets** | Show data from another system on a record page, next to the record. |

## AI Guidance

### When to Use This Feature

An AI should use Configurations when the business process needs behavior, not just data storage. If the request involves "what happens when", "who can act", "what should be generated", or "what should users see first", it belongs here.

### How to Use It

1. Start with the table and record model.
2. Add workflows for user-facing process actions.
3. Add automations for background effects.
4. Add document mappings for copying structured data between documents.
5. Add home widgets and reports so users can operate from curated views.
6. Add record widgets when users check another system for the same record.
7. Verify each change with sample records.

### How to Verify

The AI should verify configuration changes from the user's point of view:

- Can the right user see the right queue?
- Does the right button appear?
- Does the action update the right data?
- Does the automation leave visible proof?
- Does the report or widget match the table records?
