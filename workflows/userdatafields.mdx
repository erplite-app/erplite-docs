User data fields are values users enter while creating or updating records. They should be clear, minimal, and validated.

## When to Add User-Entered Fields

Add a user-entered field when:

- The user is the source of truth for that information.
- The value is needed for an action, report, or decision.
- The field cannot be derived from another record.
- The value should be searchable or filterable later.

Do not use free-text notes for important structured data.

## AI Guidance

### When to Use This Feature

An AI should add user fields when a business process asks users to capture information during a step.

### How to Use It

1. Choose the correct field type.
2. Use clear labels.
3. Add required or conditional required behavior where needed.
4. Add dropdown options for controlled choices.
5. Add column permissions for sensitive fields.

### How to Verify

The AI should verify:

- Users understand what to enter.
- Invalid or missing values are blocked.
- The field appears in the right views and reports.
- Restricted users cannot see or edit sensitive values.
