In ERPLite, day-to-day work is usually represented by records in tables, saved views, home dashboard queues, and the workflow actions available on those records.

## What Makes a Good Work Item

A work item should clearly show:

- What needs to be done.
- Who owns it.
- Which team is responsible.
- Its current status.
- Its due date or priority.
- The next available actions.
- Any related records or documents.

## AI Guidance

### When to Use This Feature

An AI should create task/work item setup when the business needs users to complete assigned work in ERPLite.

### How to Use It

1. Choose the table that represents the work.
2. Add owner, team, due date, priority, and status fields.
3. Configure views such as My Work, Team Queue, Overdue, and High Priority.
4. Add workflow actions for the steps users should take.
5. Add the work queue to the home dashboard if users need a starting point.

### How to Verify

The AI should verify:

- The assigned user can find the work item.
- The team queue shows the item.
- Overdue or high-priority views behave correctly.
- The user can complete the required workflow action.
- Target users can sign in, find the work queue, and complete the work.
