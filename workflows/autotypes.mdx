ERPLite supports several automation types. The right type depends on what should start the automation.

| Automation Type | Use It When |
|-----------------|-------------|
| **Table event** | A record is created, updated, or deleted. |
| **Workflow action** | A user clicks a workflow button. |
| **Scheduled** | A check should run at a defined time, such as daily overdue checks. |
| **Webhook** | Another system should trigger ERPLite. |
| **Account event** | User or team membership changes should trigger a follow-up. |

## AI Guidance

### When to Use This Feature

An AI should first identify the trigger. If the trigger is unclear, it should ask the business user what event should start the automation.

### How to Use It

1. Write the trigger sentence: "When ___ happens..."
2. Write the condition sentence: "Only if ___ is true..."
3. Write the action sentence: "Then ___ should happen..."
4. Choose the automation type that matches the trigger.
5. Configure and test with a sample record or event.

### How to Verify

The AI should verify the automation both ways:

- It runs when the trigger and conditions match.
- It does not run when the trigger or conditions do not match.
