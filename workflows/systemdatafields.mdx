System fields are values ERPLite manages automatically. They are useful for filtering, audit trails, automations, reports, and workflow rules.

## Common System Context

| Field or Context | Use It For |
|------------------|------------|
| **Created On** | Filtering newly created records or reporting by creation date. |
| **Updated On** | Finding recently changed records. |
| **Created By** | Audits and ownership checks. |
| **Current User** | Views such as My Work. |
| **Current Team** | Team-specific queues and access checks. |
| **Previous Record Values** | Detecting what changed in an automation. |

## AI Guidance

### When to Use This Feature

An AI should use system fields when the rule depends on who is using ERPLite, when the record changed, or what changed.

### How to Use It

- Use **Current User** for personal queues.
- Use **Current Team** for team queues.
- Use created/updated dates for freshness and overdue checks.
- Use previous values when automations should react only to a change, not every save.

### How to Verify

The AI should verify system-field behavior with different users, teams, and record timestamps.
