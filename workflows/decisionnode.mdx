Decision logic controls which path a record should take. In ERPLite, decisions are commonly implemented with workflow guards, transition visibility, validations, automations, and conditional fields.

## Decision Examples

| Decision | ERPLite Setup |
|----------|---------------|
| Amount above approval limit | Show Submit for Approval instead of Confirm. |
| Inventory unavailable | Block Dispatch and show a clear message. |
| Order cancelled | Hide production and dispatch actions. |
| Work order high priority | Route to manager queue and send alert. |
| Rejected approval | Require rejection reason and move to Rejected status. |

## AI Guidance

### When to Use This Feature

An AI should add decision logic when a process can branch based on field values, user role, team, dates, related records, or external checks.

### How to Use It

1. Write each branch in plain language.
2. Identify the field or relation that decides the branch.
3. Configure visibility, guard, validation, or automation logic.
4. Add a clear message for blocked paths.
5. Test each branch with sample records.

### How to Verify

The AI should verify every branch:

- A record that should take the branch can take it.
- A record that should not take the branch cannot take it.
- The user sees a useful explanation when blocked.
- Reports and views show the resulting status correctly.
